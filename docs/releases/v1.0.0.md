## 1. Release Highlights
Phiên bản chính thức **v1.0.0** đánh dấu sự ra đời của Hệ thống Chấm công Doanh nghiệp Bằng Nhận Diện Khuôn Mặt (**FAS**) đạt tiêu chuẩn sản xuất (production-ready):
- **Điểm danh không chạm cực nhanh**: $T_{\text{punch}} \le 350\text{ ms}$ trên CPU máy trạm phổ thông ($0\text{ VNĐ}$ GPU).
- **Chống giả mạo thụ động 2D MiniFASNet**: Điểm tin cậy $S \ge 0.85$, tỷ lệ chặn ảnh in và video replay $\ge 98\%$.
- **Guided Multi-Pose Enrollment**: Quy trình nạp mẫu 3 tư thế (Frontal, Left Tilt, Right Tilt) kết hợp OTP 6 số và cam kết điện tử Informed Consent.
- **Lưu trữ an toàn tuyệt đối**: Mã hóa độc lập AES-256-GCM cho từng vector ArcFace 512D; chính sách Zero-Photo-Upload; tự động tiêu hủy vector sau 20 ngày theo Luật Bảo vệ Dữ liệu Cá nhân 2025.
- **Sẵn sàng ngoại tuyến ($\text{RPO} = 0$)**: Lưu đệm SQLite WAL khi mất mạng; worker tự động gửi bù theo lô tối đa 50 bản ghi/lần khi có mạng lại.
- **Giám sát thời gian thực Live Dashboard**: Phát sóng STOMP WebSocket trong $\le 200\text{ ms}$, giao diện React 19 với hiệu ứng Green Flash 1.5s và 5 thẻ KPI tức thời.

## 3. Deployment & Environment Prerequisites
- Java Runtime: OpenJDK 21 LTS.
- Python Environment: Python 3.14 x64 với PySide6, OpenCV, ONNX Runtime.
- Database: PostgreSQL 16 x64.
- Container Orchestration: Docker Compose v2 (`manage-services.ps1`).
